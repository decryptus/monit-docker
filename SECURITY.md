# Security policy

## Report a vulnerability

Please report suspected security vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/decryptus/monit-docker/security/advisories/new).
Do not disclose security-sensitive details in a public issue or pull request.

Include the affected version or commit, the impact, and minimal reproduction
steps using synthetic data. Remove passwords, tokens, private keys and personal
data from reports and attachments. Test only systems you own or have permission
to assess.

Use the private advisory discussion to coordinate investigation, a fix and
public disclosure. Response and fix dates depend on the issue; this policy does
not promise a response deadline or support for every historical release.
