# monit-docker logos and icons

Ready-to-use exports of the existing project artwork. Use the horizontal logo
when the project name must be visible and the square icon for favicons, shortcuts
and avatars. The dark blue artwork is intended for light backgrounds.

Also available: [256 × 256 lossless WebP](icons/monit-docker-icon-256.webp)
and [multi-resolution ICO](icons/favicon.ico) containing 16, 32, 48, 64, 128
and 256 pixel images. The 180 pixel export is suitable for an Apple touch icon;
the 192 pixel export can be used for a web app icon. Platform backgrounds and
masking remain the responsibility of the embedding application.

## Sources and regeneration

- [Horizontal source](monit-docker-logo.png): the original image already used
  by the application documentation and project website, kept unchanged.
- [Square source](monit-docker-icon.png): the largest, 256 pixel frame of the
  favicon already used by the project website, with its alpha channel preserved.

Both sources are raster images. These exports do not add detail or enlarge the
sources. A true SVG or PDF vector master is not available in this repository;
embedding a PNG inside an SVG would not make the artwork vector-based.

From the repository root, with Python 3.10 or newer:

```sh
python3 -m venv /tmp/monit-docker-branding
/tmp/monit-docker-branding/bin/python -m pip install -r ui/branding/requirements.txt
/tmp/monit-docker-branding/bin/python ui/branding/build.py
/tmp/monit-docker-branding/bin/python ui/branding/build.py --check
```

Pillow is used only by this export tool and is not an application dependency.
`--check` compares generated bytes without changing files; use the pinned Pillow
version in the same environment for byte-for-byte comparisons. Different image
codec builds may produce different encoded bytes for the same pixels.

Open [preview.html](preview.html) locally for a light-background preview and
download links. On GitHub, click a file above and use its download button.
