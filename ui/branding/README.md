# monit-docker logos and icons

Ready-to-use exports of the existing project artwork. Use the horizontal logo
when the project name must be visible and the square icon for favicons, shortcuts
and avatars. The dark blue artwork is intended for light backgrounds.

<img src="logos/monit-docker-logo-640.png" alt="monit-docker horizontal logo" width="640">

<img src="icons/monit-docker-icon-128.png" alt="monit-docker square icon" width="128">

## Scalable SVG

- [Horizontal logo SVG](monit-docker-logo.svg), with the original 2073 × 758 viewBox.
- [Square icon SVG](monit-docker-icon.svg), with the original 256 × 256 viewBox.

Both files contain only vector paths and accessibility metadata: no embedded
bitmap, external resource, font dependency or script. Set any display width and
preserve the aspect ratio. The background is transparent and the lettering is
outlined, so the logo does not depend on locally installed fonts.

These are traced derivatives of the existing PNG artwork, not original design
masters. Curves approximate the raster contours; small pixel variations and
low-opacity edge noise are simplified into two solid colors: dark blue
`#112944` and accent blue `#3898fd`. The original PNGs and their exports remain
available when the exact raster appearance is needed.

## Sources and regeneration

- [Horizontal source](monit-docker-logo.png): the original image already used
  by the application documentation and project website, kept unchanged.
- [Square source](monit-docker-icon.png): the largest, 256 pixel frame of the
  favicon already used by the project website, with its alpha channel preserved.

Both sources are raster images. Raster exports do not add detail or enlarge the
sources. The SVG derivatives above trace their contours into scalable paths.

From the repository root, with Python 3.10 or newer:

```sh
python3 -m venv /tmp/monit-docker-branding
/tmp/monit-docker-branding/bin/python -m pip install -r ui/branding/requirements.txt
/tmp/monit-docker-branding/bin/python ui/branding/build.py
/tmp/monit-docker-branding/bin/python ui/branding/build.py --check
```

Pillow is used only by this export tool and is not an application dependency.
`--check` compares generated bytes without changing files; use the pinned Pillow
version in the same environment for byte-for-byte comparisons. Different image
codec builds may produce different encoded bytes for the same pixels.

To regenerate the SVG derivatives separately, use Python 3.12 or newer:

```sh
python3 -m venv /tmp/monit-docker-vectors
/tmp/monit-docker-vectors/bin/python -m pip install -r ui/branding/requirements-vectors.txt
/tmp/monit-docker-vectors/bin/python ui/branding/build-vectors.py
/tmp/monit-docker-vectors/bin/python ui/branding/build-vectors.py --check
```

The vector tracing dependencies are also development-only. Changing the source
artwork or tracing settings requires a visual review of curves and lettering.

Open [preview.html](preview.html) locally for a light-background preview and
download links. On GitHub, click a file above and use its download button.
